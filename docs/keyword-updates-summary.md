## 📝 **Best Practices Going Forward**

### **When Writing New Content**:

1. **Start with 6-10 keywords**:
   ```markdown
   keywords: [
     "main keyword",           # Core topic
     "main keyword variation", # Synonym
     "related topic 1",        # Connected concept
     "related topic 2",        # Connected concept
     "long-tail specific",     # Specific search
     "question-based"          # Voice search
   ]
   ```

2. **Include the main topic keyword** across related content:
   - All fractional CMO content should include "fractional cmo"
   - All strategy content should include "growth strategy" or "marketing strategy"

3. **Add semantic variations**:
   - Cost, pricing, rates, fees
   - Benefits, advantages, pros
   - Alternative, vs, compared to

4. **Think about search intent**:
   - What is... (informational)
   - How much... (research)
   - Best... (comparison)
   - Alternative, vs (decision)
