# Lead Magnet: Fractional CMO vs Sprint Cost Calculator

**Format**: Google Sheets
**CTA**: "Download the Cost Calculator"
**Use in blogs**: Fractional CMO pricing, cost comparison, when-to-hire posts

---

## Google Sheet Structure

### Tab 1: Your Costs (Interactive)

**Column A: Item**
**Column B: Fractional CMO**
**Column C: Strategy Sprint**

| Item | Fractional CMO | Strategy Sprint |
|------|----------------|-----------------|
| **Monthly Rate** | [Input: $5,000-15,000] | $0 |
| **Months Committed** | [Input: 6-12] | 0 |
| **Subtotal** | =B2*B3 | $9,500 |
| | | |
| **Hidden Costs** | | |
| Onboarding time (weeks) | [Input: 2-4] | 1 |
| Knowledge transfer when leaving | Not transferred | Included |
| Dashboard access | Ends with contract | Yours forever (1yr) |
| Documentation | Partial | Complete |
| | | |
| **Total Investment** | =B4 | $9,500 |
| **Cost per month** | =B2 | =C4/2 (~$4,750 for 2 months) |

### Tab 2: Break-Even Analysis

Shows at what point each model makes financial sense based on:
- Company revenue
- Marketing budget as % of revenue
- Time to value needed
- Ownership importance (weighted score)

### Tab 3: What You Actually Get

Side-by-side comparison of deliverables:

| Deliverable | Fractional CMO | Strategy Sprint |
|-------------|----------------|-----------------|
| Strategic framework | ✓ (in their head) | ✓ (documented, yours) |
| Dashboard | Maybe | ✓ (custom, 1yr access) |
| Campaign playbooks | Rarely | ✓ (complete templates) |
| Team training | Limited | ✓ (week 7-8) |
| Ongoing access | While paying | Forever |

## Why This Works

- **Actual utility** - They use it to make real decisions
- **Transparency** - Shows we're not hiding costs
- **Ownership** - They make a copy, it's theirs
- **Shareability** - Easy to forward to CFO/board
- **Trust building** - Helps them even if they don't hire us
